## 🎯 Problem Statement

**Making students' lives easier at DTU.**
Navigating university administration, obtaining official documents (transcripts, bonafide certificates, no-dues clearance, duplicate ID cards), and scheduling physical verifications is traditionally slow, confusing, and fragmented. Students often stand in the wrong lines with incomplete paperwork or missing fee challans.

**Solution:** **Doc IT** is an intelligent full-stack portal powered by Google Gemini 2.5 Flash that:
1. Understands natural language student administrative queries.
2. Identifies exact intents and provides official downloadable DTU forms.
3. Automatically tells students **where, which window, and when** to submit forms offline.
4. Uses **Gemini Vision OCR** to validate uploaded documents before physical submission.
5. Provides **Smart Appointment Rescheduling** with 1-click Google Calendar integration.
6. Offers **7 Built-in Smart Tools** (Eligibility Checker, Attendance Calculator, CGPA Predictor, Fee Calculator, Grievance Router, Document Checklist, and AI Form Filling Assistant).
7. Features **full multilingual support** in 7 Indian languages (English, Hindi, Punjabi, Bengali, Telugu, Tamil, Marathi) with instant Dark/Light mode.
8. Includes an **Admin Dashboard** with real-time approvals, automated calendar booking, and Gemini AI rejection guidance.

## 🚀 Getting Started

### 1. Install Frontend & Root Dependencies

```bash
npm install
```

### 2. Install Python Backend Dependencies

```bash
pip install -r server/requirements.txt
```

### 3. Configure Environment Variables

Create `server/.env` (or copy from `server/.env.example`):

```env
PORT=8000
Gemini_api_key=your_gemini_api_key_here
```

### 4. Run Development Servers

From the root project folder:

- **Frontend Client (Vite):**
  ```bash
  npm run dev:client
  ```
  *Accessible at `http://localhost:5173`*

- **Backend API (FastAPI):**
  ```bash
  npm run dev:server
  ```
  *Accessible at `http://localhost:8000` (API docs at `http://localhost:8000/docs`)*
